# Roadmap

> Where we are, where we're going, and how we'll get there.

This roadmap outlines the strategic priorities for the in/acc movement. It is a living document -- contributions, critique, and course corrections are welcome.

---

## Phase 1: Foundation (Current)

**Goal:** Establish the intellectual and community foundations for the movement.

- [x] Publish the Indic Accelerationism Manifesto
- [x] Create brand assets and visual identity
- [x] Launch the X (Twitter) Community for coordination
- [x] Open the repository for public collaboration
- [ ] Formalize the contributor framework across all seven pillars
- [ ] Publish an initial reading list and knowledge base
- [ ] Recruit founding contributors across research, policy, build, and outreach tracks
- [ ] Set up a project board for tracking active initiatives

## Phase 2: Research & Design

**Goal:** Produce rigorous, actionable research and design documents for priority areas.

- [ ] **Anti-Corruption Infrastructure**
  - Survey existing transparency initiatives (India and global)
  - Draft a design proposal for blockchain-backed procurement monitoring
  - Identify pilot-ready use cases in state/local government

- [ ] **AI for the Judiciary**
  - Map the current digitization landscape (NJDG, e-filing, case info systems)
  - Identify gaps where AI can have immediate impact (case prioritization, jurisprudence consistency)
  - Publish a technical design document for a case analysis prototype

- [ ] **Education & Skill Development**
  - Audit existing open education platforms in India
  - Design a vernacular-first, AI-personalized learning framework
  - Identify partnership opportunities with state education systems

- [ ] **Smart Infrastructure**
  - Research intelligent transportation systems deployed globally
  - Draft proposals for smart toll and predictive maintenance pilots
  - Engage with urban planning bodies for data-sharing partnerships

- [ ] **Healthcare**
  - Map India's healthcare infrastructure gaps by region
  - Design a telemedicine framework for rural connectivity
  - Propose AI-assisted diagnostic tool pilots for public hospitals

## Phase 3: Build & Pilot

**Goal:** Ship working prototypes and run pilot programs.

- [ ] Launch at least one pilot project per priority area
- [ ] Build open-source tools and platforms that embody in/acc principles
- [ ] Partner with government bodies, NGOs, and industry for pilot deployments
- [ ] Measure outcomes against the three core metrics (GDP Growth, Gini, Doughnut)
- [ ] Publish pilot results and learnings openly

## Phase 4: Scale & Advocate

**Goal:** Take what works from pilots and push for systemic adoption.

- [ ] Publish policy briefs based on pilot outcomes
- [ ] Advocate for regulatory and institutional changes
- [ ] Scale successful pilots to state and national level
- [ ] Grow the contributor community to span all seven pillars nationally
- [ ] Establish formal partnerships with public and private institutions
- [ ] Create a repeatable playbook for launching in/acc initiatives in new domains
